# Arrow Indicator

Qlik Sense extension for clean SVG arrows.

## Install

**Desktop**: copy the `ArrowIndicator/` folder into `Documents\Qlik\Sense\Extensions\`.

**Cloud / Onprem**: zip the folder and import from Management Console.

## Shapes

Eleven of them: straight, pentagon, chevron, notched, striped, two-way, four-way, elbow, curved, step (Z), U-turn. Each one has its own directions, filled or outlined, any color.

Sliders for thickness, head length, head width, border, margins. Title bar and details menu are hidden by default. Arrows keep their proportions whatever the box size, no stretching.

Works on Client-Managed and Cloud.
